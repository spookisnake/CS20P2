5. Explain the scope of each of the variables in the code below:
 	
 public class ScopeExample {
 	public static void main(String[] args) {
 		int var1;
 		for (int var2 = 0; var2 < 5; var2++) {
 		method1();
 		}
 	}
 	public static void method1() {
 		int var3;
 		for (int var4 = 0; var4 < 2; var4++) {
 		var3 += 1;
 		}
 	}
 }

var1: This variable is declared within the main method's code block. 
Its scope is limited to the main method. It can be accessed anywhere from its declaration point to the end of the main method.

var2: This variable is declared within the initialization part of the for loop in the main method. 
Its scope is limited to that for loop's header and body. It cannot be accessed outside of that specific loop.

var3: This variable is declared within the method1's code block. 
Its scope is limited to method1. It can be accessed anywhere from its declaration point to the end of the method1 body.

var4: This variable is declared within the initialization part of the for loop in method1. 
Its scope is limited to that specific for loop's header and body. It cannot be accessed outside of that loop.

11. Determine if each of the following are true or false. If false, explain why.

 a) Breaking a task down into methods is called procedural abstraction.
	True.

 b) A method call consists of the method declaration in an assignment statement.
	False. A method call is an invocation of a method. The method declaration defines the method's signature and body, while the call executes it.

 c) A void method must return a value.
	False. A void method. It does not return a value.

 d) An access modifier declares the return type of a method.
	False.An access modifier determines the visibility of a method to other parts of the program.

 e) The keyword static declares a method is a class method.
	True. 

 f) Method parameters are enclosed by braces ({}).
	False. Method parameters are enclosed by parenthesis (). Braces {} are used to define the body of a method. 

 g) Local variables can be used by any method in a class.
	False. Local variables are declared within a specific method or block and their scope is limited to that block. They cannot be used by other methods in the class.

 h) The value of an argument passed to a method can be changed in an assignment statement in the method.
	True.

 i) Method overloading means that an application contains more than 10 methods.
	False. Method overloading means that two or more methods in the same class share the same name but have different parameter lists.

 j) The return statement is used to send a value back to the calling statement.
	True.

 k) The precondition of a method states the data types of the method’s parameters.
	False.  A precondition of a method describes the conditions that must be true before the method is called for it to work correctly.

 l) The postcondition of a method describes the way the method accomplishes its task.
	False. The postcondition of a method describes what will be true after the method has finished executing.
